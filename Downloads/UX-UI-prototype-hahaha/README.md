# MRIS Frontend Prototype

This project is a pure frontend prototype for the multipurpose reforestation information system. It uses mocked tree and coordinate data to demonstrate the data entry, table, and statistics flows without any backend services.

## Run locally

Prerequisite: Node.js 18+

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Build the production bundle with `npm run build`.
4. Preview the production build with `npm start`.

## Scope

- React + Vite single-page frontend
- Mocked records loaded from local files
- No API keys, backend services, map tooling, or image upload pipeline required
